# 决策：占位文本不得当学习内容（例句与搭配的读取边界归一）

日期：2026-11-06
关联规格：`docs/specs/01-vocabulary-learning-and-review.md` AC1-12、F1-03（回忆→揭晓卡面）、F1-06
关联报告：`docs/handoff/2026-11-06-placeholder-honesty-batch-report.md`

## 背景

真机/模拟器走查（`emulator-5554`，2026-11-06）在词卡页看到卡面印着一行「暂无例句」，
像是词条自带的内容。对随包十册词书做全量统计（脚本与读数见报告 §2，可复算）：

- 十册共 **45,290** 张卡，`example` 字段**只有一个取值**，就是字符串「暂无例句」——
  真实例句 **0 条**；`exampleZh` 全为 `null`。
- `phrases`（常用搭配）共 **78,392** 条，其中 **77,358 条（98.7%）** 的 `text` 与 `meaningZh`
  **逐字相同**（如 `a lot 许多 / a lot 许多`、`非常 / 非常`），不是「英文搭配 + 中文释义」。

这串占位文本不在仓库任何代码里（全仓检索只命中 `assets/wordbooks/*/book.json` 与它们的
`mergeDebugAssets` 副本），是**外部词典源带进来的**，打包工具原样落盘。

后果是规格被数据打穿：AC1-12 明写「无数据的任一内容模块，详情页隐藏对应区域，
不出现空标题或『暂无』占位」，而卡面（F1-03 的回忆流程把「英文例句」排在卡面上）
与详情页现在都把这枚占位串当内容渲染。用户看到的不是「这条没有例句」，
而是一条**长得像例句的中文占位**。

## 候选方案

1. **改写数据**：把十册 `book.json` 里 45,290 处占位串清成 `null`。
   代价：十份大文件全量重写（随包资产，APK 体积 300MB 级），且 `CardDto.example` 目前是非空
   `String`、`validateCard` 逐条校验长度，改数据必须同时改包格式与校验；
   导入册（用户自带包）里的同类占位串仍然管不着。
2. **读取边界归一**：在包解析出 domain 卡的那一处，把「空白或整串就是占位语」的例句
   视为**没有例句**（`null`），把 `text == meaningZh` 的搭配视为**没有第二行可讲**。
   代价：需要写清"什么算占位"的判据，避免把真实内容误杀。
3. **界面各自判断**：每张卡面、每个详情模块自己 `if (text != "暂无例句")`。
   代价：判据散落多处，将来第四、第五个渲染点必然漏，且导入册走同一份数据却走不同判断。

## 决定

取 **方案 2**，并明确它的边界：

- **唯一归一点**是 `WordBookPackage` 的 DTO→domain 转换（内置册与导入册共用这一条路），
  界面不再各自识别占位串。
- 例句判据**只认整串相等**（去空白后等于已知占位语，或本身是空白），**不做子串匹配**——
  「He has no example yet.」这类真实句子、以及将来含「暂无」二字的正常中文例句都不该被误杀。
  已知占位语是一份**封闭清单**，新增一项要有数据出处，不许凭感觉加。
- 搭配判据是**结构性的**而非词表式的：`text` 与 `meaningZh` 去空白后逐字相同 ⇒ 只讲得出一个字段，
  就只渲染一个字段。这条不改数据、不删条目，只停止把同一串字念两遍。
- 卡面与详情页沿用既有 `example?.let` 与模块级隐藏，归一后自然满足 AC1-12，
  **不新增**「暂无例句」这种字样去替代它。

## 补充（同日，设备复验时发现的第二类占位）

例句归一在 `emulator-5554` 上复验时，词义详情页「常用搭配」区域露出另一路假内容：
`doctoral-english:a` 该区域只有一个标题加一行「—」。对十册重算（读数见报告 §2，可复算）：

- `phrases` 78,392 条里 **6,517 条**的 `text` 整串就是「—」；
- `synonyms` 91,971 条里 **3,224 条**的 `lemma` 整串是「—」（`meaningZh` 同为 3,224，另有 13 条写「无」）；
- `senses`（45,290 条）与 `derived`（43,684 条）里这种整串「—」命中 **0 条**——所以这一路只动搭配与近义。

决定沿用同一套判据，只是把处置从「抹掉第二行」升级为「**整条不要**」：
条目本身讲不出任何内容时，它不是内容，渲染它就是在给用户看一行破折号。

- 已知无内容记号是第二份**封闭清单**（`WordBookContentPlaceholders.NO_DATA_MARKS`，当前只有「—」），
  与 `EXAMPLES` 并列，新增同样要有数据出处。
- 仍然**只认整串相等**：`mother-to-be`、`the — not so simple — part` 这类含破折号的真实内容一律保留；
  「无」这类**可能出现在正常中文里**的字暂不列入清单（十册只有 13 条，代价与误杀风险不划算）。
- 归一点不变，还是 `WordBookPackage` 的 DTO→domain 一处；区域级隐藏由界面既有的
  `if (list.isNotEmpty())` 兑现，不新增「暂无搭配」字样去替代「—」。

## 影响

- 词卡卡面在十册里的实际呈现从「单词 + IPA + 词性 + 假例句」变成「单词 + IPA + 词性」，
  卡面更空——这是**把事实摆出来**，不是把事实藏起来；版面随之收紧（见报告 §3 词卡版面项）。
- 真实例句缺失是**内容级缺口**，不是代码缺陷，本批不解决。三条出路（AI 按词生成＝付费出站且
  要限流；换带例句的外部数据集＝先过许可核验；维持隐藏＝只缺内容不缺诚实）
  已写进报告 §5 待用户拍板，任何一条都不在本批范围内。
- 归一后 `WordCard.example == null` 的词条在十册里从 0 变成 45,290，
  所有依赖「有例句」的展示与用例都要以 fixture 数据为准，不能拿随包册当有例句的证据。
- 同一批读数下，随包册实际能渲染的搭配从 78,392 条降到 71,875 条、近义词从 91,971 降到 88,747，
  `PhraseEntry.meaningZh` 由非空 `String` 改为可空（默认 `null`）：域模型从此**允许讲不出中文释义的搭配**，
  渲染侧要按可空处理，不能再假定第二行存在。
