# F2-01 阅读访问与文章状态决策

- 日期：2026-09-22
- 状态：已接受
- 相关规格：`docs/specs/02-reading-and-ai-content.md` F2-01、AC2-01、AC2-03、AC2-05
- 实施计划：`docs/superpowers/plans/2026-09-22-f2-01-reading-access.md`

## 决定

F2-01 先建立本地文章状态、TodayPlan 解锁门禁、文章类型偏好和版本化历史读取，不在本切片发起真实 AI 网络请求。AI Profile、SecretStore、Endpoint 安全校验、出站确认和模型输出校验留到 F2-02/F2-03。

文章类型固定为 `NEWS`、`STORY`、`SCIENCE`、`WORKPLACE`，默认类型为 `STORY`。偏好按 profile 保存，改变偏好只影响未来生成，不修改既有文章。

文章长度只能使用 `SHORT`、`STANDARD`、`LONG` 三档，禁止任意词数输入。长度优先级为用户显式档位 > 词书等级默认 > 产品默认。默认标准档：小学/初中 80–120 词、高中 120–180 词、四级/六级/考研 180–300 词；短篇和长篇范围及上下 10% 验收容差固定在实施计划中。

同一 profile、日期、活动词书、文章类型和长度档下，默认复用最新成功版本。用户主动换一篇才创建新版本，旧版本继续离线可读；每日主动换篇上限为 3 次，失败不推进版本号、不修改 TodayPlan。

## 影响

- 文章实体与学习计划实体分离，TodayPlan 只提供解锁状态和缺口原因。
- 历史文章不自动清理，本阶段不设置删除上限。
- 文章内容只保存纯文本字段，不执行 HTML、脚本或外部链接。
- F2-01 不引入网络库、不引入图片/富文本库、不引入 DataStore。
