# 2026-10-25 UI 简化批：冗余控件删除

## 背景

用户要求「把每个子页面、每个菜单的排版看一遍，不合理的列出来」后拍板：**先全删这些冗余，后面再细分**。
审查依据与逐屏证据见 `docs/verification/2026-10-25-ui-ux-audit.md`。

本决策只授权**冗余控件的删除**，不授权功能下线。凡删除会移除用户内容、数据通路或已验收的安全能力者，
一律留在「保留项」里，等下一轮细分时单独裁决。

## 决定

### 本批删除（无信息损失或与在册控件重复）

1. `VocabularyScreen.kt` 整文件：全仓零调用点（死屏），「我的词」生词本段已取代。
2. 今日计划两张计数卡：数字在进度明细行与工作量图例已各出现一次。
3. 今日计划「已解锁：文章已解锁」独立句：按钮启用态与下方解锁说明已表达。
4. 今日计划「学习工具与设置」入口行：设置 tab 常驻，属重复入口；「调整词书与目标」保留。
5. 打卡页「近 7 日完成率」条：与「本周学习」条同构，保留后者与月历。
6. 默写纸预览顶部「← 返回修改」与同义副标题：底部已有返回，页数信息保留。
7. 学习设置「入门卡」：与页头副标题同义，且挡在第一个控件之前。
8. AI 配置「官网」字段（只删表单，实体/校验保留）：全仓无展示消费方。
9. AI 未上线页「还差什么」「会用到的数据」两卡：开发 backlog 面向开发者，不是用户信息。
10. 语音设置「更多语音厂商 · 待接入」折叠区：6 条全部不可点。
11. 我的词错词段排序说明句：结果框保留（它承载失败反馈，属功能）。
12. 学习记录行内「释义：」前缀；「反馈：」保留（connected 用例按该文本取证）。
13. 许可证页「共收录 N 项」：无决策价值。
14. AI 问词「个人笔记」问法 chip：本地笔记已有输入框，且该 chip 实际走统一 `ask()` 发 AI 请求，
    与 `WordQaPromptKind` 注释「不参与 AI 问答」冲突。
15. 设置页资料卡：昵称并入页头副标题，词书名并入「词书与每日目标」行副标题，信息不丢。
16. 词卡第二行任务计数：保留「第 x / y 张」，删除「到期复习 x/y / 今日新增 x/y」。

### 保留项（本批不删，下一轮单独裁决）

| 项 | 不删理由 |
|---|---|
| 备份中心两条导出（默认 / 认证） | 认证导出是 F4-04 安全能力，删 UI 等于下线功能 |
| 文章阅读「全文对照」模式 | 删除会下线一种阅读模式，不只是去重 |
| 词书单词字母栏 / 筛选条 | 二选一是导航方式取舍，且字母栏刚完成 48dp 验收 |
| 学习设置 4 个详解开关 | 删除会改变词卡内容呈现，属行为变更 |
| 拍照翻译离线模型卡 / 已保存历史 | 分别是离线降级能力与已保存用户数据 |
| 词义详情内置配图回退 | 有图的词会失去真实内容 |
| 我的词「已掌握」结果框 | 承载失败反馈（StorageUnavailable 零反馈缺陷的修复），不是冗余 |
| 查词入口整卡 | 必须四态常驻（AGENTS.md 离线查词要求），只能改形态不能删 |

## 影响

- 规格：`docs/superpowers/specs/2026-10-17-ui-redesign-design.md` 未逐条钉住上述控件，本决策作为覆盖记录；
  后续 Task 35（页头收编）/ Task 26（批 3 收口）以本文件为准。
- 测试：所有「断言控件存在」的 JVM/connected 用例改为「断言不存在」或改锚到替代控件；
  词行族/共享组件棘轮中 `VocabularyScreen.kt` 的留档条目随文件删除一并移除。
- 不涉及的：数据层、Room、备份格式、AI 请求策略、无障碍语义（删除控件不新增不可达节点）。
