# 设置升为第五个一级 tab，信息入口去重

- **日期：** 2026-10-31
- **状态：** 已接受（用户拍板：结构性重排，新批次）
- **关联：** `docs/design/2026-10-31-information-architecture-audit.md`（盘点与 A/B/C 方案）、
  `docs/superpowers/specs/2026-09-23-ai-learning-tab-design.md`（四栏导航规格）、
  `docs/decisions/2026-10-17-ui-redesign-information-architecture.md`（「底部四栏不动」的旧约束）

## 背景

用户在真机走查中指出：「我的里面有一个关于跟开源许可与隐私说明，那个开源许可与隐私说明，在关于里面也有一个叫开源许可与来源，这是重复的」，
并要求把全应用每个功能与位置重新考虑一遍。

盘点（见审计文档）确认三处重复：

1. `LicensesScreen` 两个入口：设置「外观与关于」行与关于页「开源许可与来源」行，同一页三个名字；
2. `BackupHubScreen` 两个入口：设置「数据与安全」行与关于页「备份与恢复」行；
3. 关于页「隐私说明」是 `onClick = null` 的死行，副标题「可随时导出」实际描述备份，隐私正文只在许可页首段。

根因不是单行文案，而是「设置长在『我的』页下半屏」：一个 tab 同时承担个人进度与全部设置，
于是「关于 / 许可 / 备份」既像设置又像信息，出现在两个语境里。

用户在三套方案（A 最小去重 / B 关于做信息中心 / C 结构性重排）中**选择 C**，
并同时裁定：AI 助学页**暂不**增加配置入口。

## 候选方案回顾

- **A 最小去重**：关于页删两行、许可行改名；不动导航。代价最小，但「设置长在我的页里」的根因保留。
- **B 关于做信息中心**：设置只留会改状态的行，备份/许可/隐私迁到关于。备份是操作不是信息，放在关于下不直观。
- **C 结构性重排**（采用）：设置独立成第五个一级 tab，「我的」回归个人进度；关于页只保留真正的「关于」信息。

## 决定

1. **底部导航改为五栏**，顺序固定：
   `学习 / 阅读 / AI 助学 / 我的 / 设置`。
   - `AppTab` 枚举新增两项语义：`PROFILE`（我的）与 `SETTINGS`（设置）。
     现状是 `SETTINGS` 这个名字承担「我的」的语义，必须改名而不是叠加，否则代码语义与界面相反。
   - 第五格字形取 `AppIcon.Gear`（图标台账第 25 条原本就写着「底导『设置』tab」），
     第四格保持 `Person`。
2. **「我的」= 本人进度**：档案头 + 三格统计（已学词 / 连续天数 / 文章）+ 学习记录行；
   **不再**内联设置分组。`ProfileScreen` 的 `settingsContent` 槽移除。
3. **「设置」= 唯一调整入口**：独立 tab 根页（页头「设置」+ 滚动区），承载原四组：
   学习（词书与每日目标 / 学习提醒 / 生成默写纸）、AI 与语音（AI 服务与密钥 / 语音朗读）、
   外观与关于（主题 / 关于）、数据与安全（词书内容包 / 备份与恢复）。
4. **关于页只做「关于」**：
   - 保留：应用块（名称 + 版本 + 单机优先）、隐私一句话、「开源许可与隐私说明」入口、致谢；
   - **删除**「备份与恢复」行（备份唯一入口在 设置 → 数据与安全）；
   - **删除**不可点的「隐私说明」死行（隐私正文的唯一出处是许可页首段）；
   - 许可行改名，与设置侧与页面标题**逐字一致**为「开源许可与隐私说明」。
5. **设置侧删除重复的「开源许可与隐私说明」行**：许可唯一入口在 关于 → 开源许可与隐私说明。
   「外观与关于」组只剩 主题 + 关于。
6. **备份与恢复唯一入口**：设置 → 数据与安全 → 备份与恢复。
7. **AI 助学页不加配置入口**（用户裁定「暂不加」）：配置仍在 设置 → AI 与语音 → AI 服务与密钥，
   功能页内「去配置 AI 服务」保持直达。
8. 学习页页头齿轮的原语义是「去设置」，改动后落到**设置 tab**（而不是我的页顶部）。

## 为什么是期望值变化，而不是放宽

- `AppTabTest` 原钉「恰好四栏」、`AppBottomBarTest` 原钉四枚节点，都是**被取代的期望**：
  用户明确要求把设置独立成一层。测试跟着改是需求变化，不是为了让代码过关而删断言；
  新的期望只会更严（五栏顺序 + 每格标签唯一 + 两页各自的语义边界）。
- 「我的」页的 `ProfilePageContractTest` / connected `ProfileScreenTest` 去掉设置槽后，
  仍要钉住三格统计与学习记录行；设置侧新增自己的页面契约，不允许「拆开后两边都少测」。

## 风险

- 五栏在 360dp 窄屏上的标签宽度：`AI 助学` 四个字 + 五格均分，labelSmall 下需实测不折行；
  若折行，退路是把「AI 助学」缩为「AI」（须再经用户定名，不得自行改标签）。
- 历史用户的心智迁移：设置不再在「我的」页里；学习页齿轮与「我的」页都应有清晰指向。
  本轮只保证入口可达与状态保存正确，不额外加引导。
