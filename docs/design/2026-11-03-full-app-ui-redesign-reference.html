Section 00

怎么读这份稿

给实现方：先说清这份文档的效力边界、标注约定，以及每一屏的四件套分别对应 Compose 里的哪一层。

效力边界

这份稿管什么
  • 每一屏从上到下的版式顺序（哪个容器、什么档、几 dp 间距）
  • 颜色、字号、圆角、触控尺寸的具体数值
  • 空态 / 加载 / 失败 / 未配置 / 大字号下的呈现规则
  • 「与今天比改什么」——差分清单，改完这条即视为达标
这份稿不管什么

  • 文案终稿（逐字保留现有中文，稿中引用的都是源码原文）
  • 动效时长曲线（沿用主题默认，仅在必要处标注）
  • 已叫停的功能项（见下）
已叫停、本轮不要碰

Section 01

设计基座

所有屏共用的一套令牌。数值与源码权威档逐字一致——theme/AppColors.kt、AppType.kt、 AppShape.kt、components/Containers.kt。不要引入第七种颜色、第七档字号、第四种容器。

1.1 · 七域色板

每个域有三枚：base（正身）、light（浅底）、deep（墨）。 域色的唯一职责是「告诉用户这是哪一类事」，不承担装饰。

域色的三条硬规则
  • 数据形状（进度条、圆环、占比条）一律 base → deep 双色渐变，绝不用 LocalContentColor。 这是缺陷 ① 的根因，见 §5.1。
  • 浅底只用来铺「整块的小面积」：徽标 backdrop、徽章、内联提示，且透明度另有规定（见 1.6）。
  • 同一屏最多出现两个域色。第三个别进来之前，先问「这屏到底属于谁」。

1.5 · 容器三档

整个 App 只有三种「块」。每一个版式带都必须是这三档之一或裸内容——这是保证 37 屏长得像同一套东西的根本。

一屏至多一枚。圆角 28dp，内边距 18dp，带间 10dp。浅套 tint2 底 + text1 墨；深套 strongSurface + onStrong。只用来装「今天最重要的那件事」。

SoftCard

圆角 20dp，内边距 16dp（装裸行时传 PaddingValues(0.dp)），带间 8dp。不描边，只靠明度差分。 次要分组用它。

BareRow
学习提醒 每天最多一次，系统可能稍有延迟 ›
语音合成 当前供应商：系统 TTS ›

最小高 52dp，内边距 15/13，图标—文字间距 12dp。分隔线左缩进 52dp（= 40dp 徽标 + 12dp 间距）， 从文字起点起笔。线画在 padding 外侧，不吃高度。

三档的红线
  • 不许套娃：StrongCard 里不许再放 SoftCard；SoftCard 里放裸行时内边距归零。
  • 不许自造第四档：遇到「需要一点底色」的场景，先找 tint / InlineNotice，而不是再包一层圆角矩形。
  • 一屏一个强档卡。第二枚出现时，正解是把其中一枚降为 SoftCard 或裸行。

Section 03.5

宿主壳 AppScreen

37 屏之外的那一个：它不管内容，只管路由、底导、启动面与十二个浮层的托管。改它等于改全部屏的外框，所以单独一节。

五段职责
  • 启动面 BrandLaunchSurface：品牌渐变条 + 标识，仅冷启动 1 帧。
  • 状态分派：Loading / NeedsProfile / Ready / Error / NeedsRecovery 五种整屏。
  • 底导：四个顶层 Tab 才有；进入二级页一律隐藏。
  • 浮层托管：十二个弹窗全部挂在这一层（见 §4），屏内只发「请求」。
  • 系统 inset：状态栏 / 导航栏 / 键盘，统一在这里吃掉。
硬约束
  • 屏不发弹窗：屏只回传「我请求删除 X」，由宿主弹共享确认框。这条是现有架构的正确做法，必须保持。
  • 破坏性确认不可绕过：ConfirmDestructiveDialog 的两步确认是红线（先请求、再确认）。
  • 底导只在四个顶层出现，二级页（词义详情、读文章、AI 服务等）一律无底导。
  • 内容底边距 = 64dp 底导 + 系统 inset + 16dp；漏了就会蹭底导。
底导四格已定名

第三格从占位名收口为 「AI 助学」（AppTab.AI("AI 助学", "AI 助学")），标签与朗读描述同一串。 四格 glyph 固定为 Book / Newspaper / Spark / Person，不再换。

D10 · 通用规矩：入场与遮罩

动效
  • 居中对话框：遮罩淡入 120ms + 面板 0.96→1.0 缩放 160ms（FastOutSlowIn）。
  • 底部抽屉：位移上滑 220ms，遮罩同时淡入。
  • 关闭：一律 120ms 淡出，不做反向缩放（会显得拖）。
  • 系统「减少动画」开启时，全部降为纯淡入淡出。
遮罩与层级
  • 遮罩：text1 @32%（浅套）/ #000 @48%（深套）· 不用模糊（模糊会让长正文读不清）。
  • 遮罩点击 = 取消；破坏性面板（D1 不可逆态）遮罩点击无效，必须显式点。
  • 同一时刻只有一层浮层。第二个浮层不得叠上来——需要串行就关一个再开一个。

D11 · 通用规矩：键盘、返回键与无障碍

键盘与 inset
  • 只有 D5（笔记）与 D9（输入模式）吃键盘；其余浮层在键盘弹起时先收键盘。
  • 面板底部内边距要加导航栏 inset，否则三键导航下按钮贴边。
  • 底部抽屉的高度上限要扣掉键盘高度，不要盖住输入框。
返回与朗读
  • 返回键 = 取消，一律如此（含破坏性面板）——把用户关在弹窗里是错的。
  • 浮层打开时焦点锁在面板内，TalkBack 焦点先落标题再落按钮。
  • 朗读顺序：标题 → 正文 → 主键 → 次键。危险主键的朗读文本要带动作名（「删除全部学习数据」），不能只读「删除」。
