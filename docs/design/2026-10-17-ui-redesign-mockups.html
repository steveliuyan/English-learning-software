薄荷玻璃 · 设计系统重设计稿

这是 UI 重设计轮批 1 的视觉基线，不是生产代码。所有取值都是本仓库当场算过的：色值来自 ui/theme/AppPalette.kt、MintPalette.kt 与 docs/design/visual-style-guide.md；对比度按 WCAG 2.x 相对亮度公式现算。 设备框按 360dp 真比例绘制（1px = 1dp），字号与间距用同一套变量，缩放控件会同时作用于四屏。

一句话结论：问题的根源不是薄荷玻璃不好看，而是没有装配点——全仓没有一处 MaterialTheme(...)，206 处 MaterialTheme.typography 吃的是 Material 3 默认字号，与已定义的薄荷六阶无关；深色模式也因此没有落点（DarkColorScheme、 isInDarkTheme 全仓 0 命中）。本稿先定 token 与组件，再让 33 屏逐个接上。
