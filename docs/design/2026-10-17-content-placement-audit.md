# 逐屏内容归属与简洁度审计（UI 重设计轮 · 2026-10-17）

**结论一句话**：现状的「乱」不是配色问题，是**同一件事在多屏重复呈现 + 页面承担了别人的职责**。
本轮把 33 屏逐屏读完，按「这一屏唯一职责是什么」判定每个内容块的去留，
并把需要拍板的信息架构取舍与不需要拍板、直接按规范修的缺陷分开。

- 审计方式：5 个只读子代理按域分组逐屏读源码（附录见文末），产出渲染顺序清单 + 每屏一行结论 + 动作表；
  主控对全部高影响主张逐条回源码复核，**包括推翻我自己上一轮的两条错误结论**（见 §2）。
- 口径：只评**内容归属**与**简洁度**。配色、圆角、字号、图标风格归批 1 视觉稿
  （[`2026-10-17-ui-redesign-mockups.html`](./2026-10-17-ui-redesign-mockups.html)），本文不重复。
- 硬约束：底部四栏（学习 / 阅读 / AI 学 / 设置）与 `AppTabTest` 钉住的顺序不动；
  FSRS 复习、每日计划快照、解锁规则、备份认证与配对语义、删除级联确认，**业务规则一律不碰**；本轮不新增功能。
- 所有行号取自当前工作区（`app/src/main/java/com/example/englishlearning/`），`AppScreen.kt` 实测 **2424 行**。

## 1. 全局结论（五条）

1. **今日计划页是重灾区**：Ready 态从上到下 17 个渲染块、连 CTA 共 **8 个整宽按钮**（`TodayPlanScreen.kt:148-283`），

   跨 tab 再说 2 遍（`SettingsScreen.kt:159-167`、`AiLearningScreen.kt:252`/`:276-279`，三者同源 `AppScreen.kt:1573-1574`）。

   词行组件有 **7 份私有实现、0 复用**，`ui/components/` 下只有 3 个玻璃组件可复用。

## 5. 每屏一行结论（33 屏）

**学习主路径（G1）**

1. 词书选取：只留「标题 + 一句引导 + 册列表 + 每日目标滑杆 + 保存」；删整张 `SetupIntroductionCard`（`AppScreen.kt:2058-2074`）与情绪副标题（`:1956-1960`）二选一；4 张开关卡（`:2001-2024`）移出到设置域。
2. 今日计划：只留「册名 + 今日两个数 + 一条可视化 + 开始 CTA + 一组入口行」；两个切 tab 的按钮删、4 个整宽按钮合并、查词条移出页首、`调整词书与目标` 压进汇总卡。
3. 词卡：只留「一张卡 + 显示释义 + 发音 + 三档反馈」；卡上「词形变化」移交详情（`:312-322` vs `CardDetailScreen.kt:257-261`）、两个同格式计数器并一行（`:179-186`/`:187-199`）、MissingSetup 补出口。
4. 词卡详情：只留「词 + 音标发音 + 释义 + 例句/配图/关联」；4 个关联小节合成一张「关联」卡（`:239-261`，6 个同级标题见 `:178/204/240/246/252/258`）、笔记录入口只留弹窗一处、操作行按域分行。

**词汇资产与记录（G2）**

5. 词书单词：只留「字母分组 + A–Z 栏 + 两行词卡行」；删 FSRS 状态筛选（`:200-220`）与每行状态标签（`:254`），改掉不适用的「不在当前词书中」（`:255`）。
6. 查词：只留「输入 + 结果/历史 + 一行常驻词典覆盖披露」（`:232` 前移）；删与按钮重复的 Idle 提示条（`:189`）与全宽搜索 CTA（`:138-146`）。
7. 生词本：只留「一行 lemma + 一条释义 + 加入时间 + 一个处理动作」；例句/派生/短语/近义词交还详情（`:148-183`），删行内「查看详情」（`:185`）与成功弹窗（`:83-90`），「标记已掌握」与「开始重新学习」只留一条路径。
8. 重学：只留「第 x/y + 卡面 + 三档反馈 + 完成收口」；返回文案按宿主区分（`:26`/`:52`），失败归因改掉（`:32`）。
