1. **4 张开关卡（`2001-2024`）不属于「选册 + 定目标」**。其中 `显示词汇搜索次数`（`2019-2024`）是查词/搜索历史域设置，与词书、目标毫无关系；三档「提交后查看词义详情」是学习偏好，`SettingsScreen.kt:172-177` 已把这组开关归到「调整词书与目标 · 换词书、改每日新增量、改反馈后的详情开关」的说法下，说明它的正牌归属是设置域。去处：设置 →「调整词书与目标」的下一层；本页最多留一行「反馈后自动查看详情：认识 关 · 模糊 开 · 忘记了 开 ›」的入口行。
