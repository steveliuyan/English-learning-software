01诊断：为什么现在看起来单调

「单调」不是配色问题，是层数问题。用户看到的功能入口图标几乎全部只画了一层骨架。

决策记录里已经复现过结论：33 枚字形里，绝大多数在生产界面上只剩「一个 tint 底 + 一根 2px 线」。 AppGlyphLayer.StrokeOnly 只画描边骨架层，而功能入口的弱档容器（EntryIconTone.Tint） 与行内徽标（InlineIconBadge）走的都是这一档。两层 duotone 的底幅只在 EntryIconTone.Gradient 实底档出现，而那一档在生产里只有设置页两行。

结论
  • 要消除「单调」，必须让功能入口这一族离开 StrokeOnly，而不是再调一次底色。
  • 真正承载识别特征的仍然是骨架层（裁决 22-1 不许放松）；底幅与强调层只解决「体量感」与「笔触感」。
  • 行内 17dp 与 30dp 容器不上三层：尺寸太小，底幅会把字形糊成一坨，这条路必须留着单层。
  • 「今日计划」两行连徽标容器都没有，是这次唯一需要新增容器的落点——它决定了三层能不能覆盖到首屏。

「建议」与「现行」差在哪

「现行」按 2026-10-19 决策记录第 4 条：实底渐变档的强调层取域 base。 实测这条取不到的对比——base 正好坐在「渐变底」与「白 42% 底幅」之间， 强调层压底幅只有 1.01–1.47，等于不可见（明细见 §4）。 「建议」把强调层改为取墨：实底档取「域深再压暗 18%」（深套取 onBrand），弱档取域 deep， 强调层压底幅升到 2.93–4.44（深套 5.91–9.74）。两档切换可直接对看。

4.4 轻松档：把压力从三处降下来（2026-10-27 已采纳并落地）

学习软件的压力感很少来自「品牌色是青绿」这件事，而是来自三处叠加。本节给一套不换品牌识别的降压力取值； §2 / §3 / §5 三处预览的「配色」开关已经接上，可以整片对看。 本节取值已全量落进 ui/theme/AppColors.kt（决策 docs/decisions/2026-10-27-relaxed-palette-rulings.md，验收 docs/verification/2026-10-27-relaxed-palette-d7.md）；容器渐变亮端也随之由 35% 收到 18%。

压力来自哪三处。

  • 七个域色是系统色原值。#0A84FF / #FF375F / #BF5AF2 / #FF9F0A 单看都没问题，但七组同屏、四层叠（页底 / tint / 底幅 / 描边）一直在高明度高饱和区间亮着，平均 HSL 饱和度 78.6%。
  • 中性层也泛绿。页底 #F1FBF5、tint #DDF7E8、描边 #ADE7D2 三级都带绿， 整页没有一块真正中性的休息区，眼睛一直泡在同一个色相里。
  • 渐变和深卡在拉重量。实底容器是 deep → deep 混 35% base 的多彩渐变，跨度大； 学习首页的强卡 #0C2A22 接近黑绿，是「重」的主要来源。

轻松档只动这三点：域色降彩度、抬明度（平均饱和度 78.6% → 49.9%），中性层去绿（页底、tint、描边全部退向中性）， 渐变亮端混比 0.35 → 0.18（容器从「彩色渐变」变成「近乎纯色」），强卡从 #0C2A22 抬到 #1F4739。 品牌识别仍是青绿，只是从「七种高饱和色各喊各的」变成「一片安静的浅底 + 少量柔和域色标记」。

轻松档降的是彩度，不是可达性
  • 正文对比仍是 ≥ 4.5:1，字形与图形仍是 ≥ 3:1，强调层可见性 ≥ 1.5 这条新契约照旧成立。
  • 降下来的是：平均 HSL 饱和度 78.6% → 49.9%（浅套 base）、70.7% → 51.7%（deep）、渐变跨度（混比 0.35 → 0.18）、描边浓度、强卡亮度差。
  • 品牌识别不动：主色仍是青绿，只是把「七个高饱和色同时喊」换成「一片安静浅底 + 柔和域色标记」。
  • 深套同口径下调后：墨压容器底 5.62–8.90、墨压底幅 3.40–5.11、域色压深 tint 6.12–9.70，全部达标。
两条不要越过的线
  • 底幅与强调层都是装饰性面，不承载识别特征；识别特征一律在骨架层（裁决 22-1）。
  • 三层同时存在时，灰度打印下骨架必须依然可读——§3 的「去色」开关就是这条的检查口。

四条不可越的规则

  1. 骨架层是唯一承重层。底幅与强调层都是装饰性面，任何识别特征（点、旋钮、圆章）必须在 strokePaths 里有一份。
  2. 强调层是可选实参，不是新枚举值。accent / bodyInk 缺省时行为与上一版逐像素相同，既有调用点零改动。
  3. 层开关与笔是两件事。AppGlyphLayer 管「画几层」，accent 管「用第几支笔」，不合并成一个枚举。
  4. 17dp 与 22dp 裸字形恒为单层。小尺寸上底幅会把字形糊成一坨；三层的准入门槛是 40dp 入口容器。
