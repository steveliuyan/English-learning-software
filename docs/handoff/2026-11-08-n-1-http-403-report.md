## 2. 完成了什么

**根因（两层，已取证）**：外部配置故障——网关 `www.sssai.xin` 把密钥所属分组删了，
`GET /v1/models` 与 `POST /v1/chat/completions` 都回 `403 {"code":"GROUP_DELETED","message":"API Key 所属分组已删除"}`；
内部缺陷——除「测试连接」探活外，六条带密钥的响应路径的状态码判据都只写了 `401`，403 落到「返回内容不合格」，
用户动作也因此指错（`RegenerateContent` 而非 `ConfigureProfile`）。取证原文与判点表在决策册 §1。

**改动清单**

  `FetchArticleUseCase` 未动）、`GeneratedImageStore` 无密钥 CDN 例外的理由、§6 验证口径。
