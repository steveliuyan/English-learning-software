# 工作报告模板（会话结束时必填）

**说明：** 每次开发会话结束前，AI 助手必须按本模板写一份报告，保存为
`docs/handoff/YYYY-MM-DD-<branch-or-topic>-report.md`，随代码一起提交推送。
下一任 AI 只需读"会话交接简报 + 最新报告"即可接续工作。

---

# 2026-MM-DD <功能名> 工作报告

## 1. 本次目标

（用户原话要做什么，一句话）

## 2. 完成了什么

- 具体改动清单（文件/模块级别，不要贴代码）
- 新增/修改了哪些 Spec、计划、决策文档

## 3. 验证记录

- 跑了什么命令，结果如何（RED→GREEN 记录、测试数量）
- 例：`:app:testDebugUnitTest` 1025+X 用例全绿（先 `:app:assembleDebug`）
- detekt/ktlint 增量：+X 条，处理/保留理由

## 4. Git 状态

- 分支名、提交哈希、是否已推送 GitHub
- 未提交的遗留文件及原因

## 5. 未完成 / 遗留问题

- 明确列出没做完的、被搁置的、需要用户拍板的

## 6. 下一任接手须知

- 接手第一步做什么
- 有哪些坑（环境、flaky 测试、特殊配置）
- 相关联的文档路径

## 7. 用户确认过的决策

（本次会话里用户拍板过的事项，避免下次重问）
