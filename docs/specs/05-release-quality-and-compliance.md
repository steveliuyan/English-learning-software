# 阶段 5：发布质量、可访问性与许可证治理 Spec

## 目标

证明应用在真实 Android 环境中具备可用性、离线可靠性、隐私边界、资源合规性与可发布质量。

## 前置

阶段 0–4 的范围已实现或明确裁剪；第三方依赖台账完整。

## 范围

### F5-01 质量门禁

- 为每项阶段验收标准建立可追踪测试：单元测试、数据库迁移测试、集成测试、设备/UI 测试或明确的手工验证脚本。
- 重点负向测试：重复反馈、跨日/时区、断网、AI 错误、AI Key 脱敏、缓存篡改、图片未确认上传、备份认证失败和导入原子性。
- 建立发布前检查：静态检查、单元测试、UI 测试、依赖漏洞检查、许可检查、APK/AAB 构建与签名验证。

### F5-02 性能与可靠性

- 在阶段 0 确定的最低支持设备上定义并测量：离线冷启动、今日计划读取、词卡翻页、单词查询、学习事件写入、大型备份校验与恢复的性能目标。
- 所有 AI/网络操作必须可取消、带超时且不可阻塞 UI；失败重试不得重复生成学习事件或损坏文章版本。
- 存储空间不足、模型下载中断、资源损坏、数据库迁移失败均应以可恢复错误呈现。

### F5-03 可访问性与兼容性

- 关键流程支持动态字体、深色模式、小屏与 TalkBack：可访问标签、焦点顺序、状态播报、按钮大小和颜色对比度。
- 发音提供播放、暂停、重播和速度调节；无网络/无可用 TTS 引擎时提供文字状态。
- 覆盖有 GMS 与无 GMS 设备的 OCR 降级；覆盖 Android 13+ 通知权限限制。

### F5-04 隐私、许可与发布审核

- 完成每个依赖、词书、词典、音频、Piper 模型、TalkifyTTS/云端服务的许可证、来源、NOTICE、商业使用、再分发和隐私数据流审核。
- 应用内提供“关于与开源许可”页，展示必要声明、链接和第三方服务隐私说明。
- 未核验的非商业模型、强 Copyleft 静态依赖或无授权词书不得进入发布构建。
- 发布说明明确：无账户、无自动云备份、AI 为用户自配、Key 不导出、照片发送第三方前需确认。

## 验收标准

- AC5-01：每个 `docs/specs/00` 至 `04` 的验收项都关联至少一项自动化测试或可重复的手工测试脚本，并在发布构建中通过。
- AC5-02：离线模式下，词书学习、复习、已缓存文章阅读、离线查词和可用系统 TTS 均可完成；AI 功能给出离线状态而不阻塞 UI。
- AC5-03：TalkBack 能完成选择词书、开始学习、提交三档反馈、查看完成状态、打开历史文章和进入数据管理入口。
- AC5-04：第三方台账无缺项，所有发布资源均通过许可证和商业分发审核；“关于与开源许可”页可访问。
- AC5-05：导出包、日志、崩溃报告和发布构建扫描均未发现 API Key、Authorization Header、明文密码或设备私钥。

## 发布阻断条件

- 任一备份验证失败路径会写入正式数据。
- API Key 或密码出现在日志、导出包、截图诊断或业务数据库。
- 未取得词书、词典、模型或音频的发布许可。
- 离线学习、复习或已缓存阅读被 AI/网络失败阻塞。
