# 阶段 2：每日文章、双语阅读与自定义 AI Spec

## 目标

让用户在阶段 1 已解锁时按当天完成词获得一篇复习短文；文章可来自用户自配 AI 生成、已核验许可的外刊抓取或用户自行粘贴导入；确保任一来源不可用时都不影响学习完成和历史阅读。

## 前置

完成阶段 0、阶段 1；需要 `AiProvider`、SecretStore、TodayPlan 解锁状态、文章本地存储和已核验许可的文章来源注册表。

## 范围

### F2-01 阅读访问与文章状态

- 仅在 TodayPlan 已解锁时允许产出当天推荐文章；历史文章在任意日期可离线重读。
- 用户可选新闻、故事、科普、职场；保存默认文章类型偏好。
- 最终文章长度优先级：用户显式档位 > 词书等级默认 > 产品默认。默认标准档：小学/初中 80–120 词、高中 120–180 词、四级/六级/考研 180–300 词。
- 简短、标准、长篇的数值范围与长度容差由实现计划锁定；输入值必须受限，禁止任意长度。

### F2-02 AI Profile 与安全调用

- 支持多个 OpenAI-compatible AI Profile：名称、官网、HTTPS 公网 Endpoint、模型、能力（text/vision/tts）、高级参数及 SecretStore 的 Key 引用。
- Endpoint 必须通过 AGENTS.md 定义的 URL 与网络安全校验；Profile 切换不得复用其他 Profile 的 Key。
- 调用前显示域名和数据出站确认；文本能力调用首次确认，图片能力每次确认。
- 只允许 `temperature`、`top_p`、`max_tokens`、`timeout_seconds` 与受控系统提示模板；按 AGENTS.md 范围拒绝未知参数。
- 按错误类型返回可行动状态：未配置、能力不支持、离线/DNS、401、429、5xx、超时、取消、响应不合格。

### F2-03 文章产出与质量校验

- 产出请求包含：当天完成词集合、词书等级、类型、最终长度、语言偏好和已知排除条件。
- 产出结果必须含标题与英文正文。中文翻译在 AI 生成来源下必需；在外刊抓取与用户导入来源下允许缺失，缺失时明确展示「该来源无中文翻译」并禁用全文翻译切换，不得伪造译文。
- AI 生成来源下，AI 返回必须包含标题、英文正文和中文翻译；系统派生词汇命中位置和未覆盖词列表，禁止信任模型提供的高亮坐标。
- 保存前校验（三种来源共用）：字段完整、正文非空、英文语言符合预期、长度处于容差、输出大小受限、无危险富文本/脚本、内容安全策略通过。抓取内容与导入内容与 AI 输出同样按不可信输入处理。
- 同一日期、活动词书、文章类型与长度档默认复用成功结果。换一篇必须由用户主动触发，并保存新版本、产出时间与来源。AI 生成来源另行保存模型名与参数摘要（不含 Endpoint 与 Key）。每日重生成次数与历史保留上限由实现计划决定并显示成本提示。

### F2-04 阅读体验

- 提供英文原文、可展开的全文中文翻译、高亮目标词、未覆盖词列表、点击词的离线词典入口与发音入口。
- 默认显示模式可设置：英文优先、双语对照、默认展开全文翻译；切换只改变展示，不改写文章。
- 内容只以安全文本/受控富文本渲染，禁止 HTML、脚本、外部链接自动执行。

### F2-05 离线降级

- 已缓存文章、译文和本地词典释义必须离线可读。
- 无网络、未配 Key、AI 失败或抓取失败时：保留今日已完成状态；显示重试、检查配置或阅读历史文章入口；不得显示伪造文章或将失败当成功。

### F2-06 文章多来源

- 文章必须标注来源，且来源只允许三种：AI 生成、已核验许可的外刊抓取、用户自行粘贴导入。来源元数据随文章保存，历史文章可追溯。
- 来源必须在类型层面携带各自必需的元数据，使「抓取来源缺少许可说明或署名」这类状态在编译期不成立，而不是依赖运行时校验。
- 外刊抓取只能从已登记的来源白名单发起。白名单条目须已在第三方台账完成许可证、来源、商业使用、再分发、署名与 NOTICE 位置的核验；禁止按任意 URL 抓取，禁止用户自定义抓取目标。
- 抓取结果必须展示来源署名与原文链接文本；链接不自动打开，须用户主动点击并先给出域名确认。
- 用户粘贴导入不联网、不抓取、不访问任何外部服务；用户对其提交内容的合法性与使用权负责，应用只做不可信输入校验与本地存储，并须在界面上说明这一点。
- 三种来源产出同一个领域类型，共用质量校验、结果复用、派生高亮、未覆盖词、阅读展示与离线缓存；不得为某一种来源分叉出平行的展示链路。
- 离线缓存边界：只缓存白名单来源允许本地存储的内容。来源的许可发生变更或撤销时，必须能通过白名单下线该来源，并停止其后续抓取与新缓存。

## 验收标准

- AC2-01：严格模式未满足 TodayPlan 解锁条件时，文章生成入口不可用并显示新增/复习不足原因；已解锁时可进入类型选择。
- AC2-02：AI 生成成功后文章含标题、英文、中文翻译、派生高亮与未覆盖词；文本不执行脚本或外部链接。
- AC2-03：同日同类型同长度重复进入复用同一文章；用户触发换一篇后生成新版本，旧版本仍可读。
- AC2-04：未配置 Key、HTTP Endpoint、私网 Endpoint、401、429、超时和畸形响应均返回对应可操作错误，学习完成状态保持。
- AC2-05：断网后已缓存文章可阅读；不可产出新文章且不会损坏今日计划。
- AC2-06：备份逻辑快照与日志中只保存 Profile 非敏感字段和脱敏诊断，不含 API Key 或 Authorization。
- AC2-07：阅读页与历史列表显示来源标识。AI 生成显示模型名，外刊抓取显示来源名称、署名与原文链接文本，用户导入显示导入时间；三者都不显示任何 Key 或 Endpoint。
- AC2-08：抓取请求只能发往白名单内的来源域名；白名单之外的 URL 或用户自定义抓取目标一律被拒绝并返回可操作提示，且不发起任何网络请求。
- AC2-09：用户粘贴导入的内容经过与 AI 输出相同的不可信输入校验；超长、非英文、含脚本或危险富文本的输入被拒绝并给出具体原因，且不写入数据库。
- AC2-10：抓取或导入失败（来源不可达、解析不出正文、正文不合法、无网络）时保留今日已完成状态，显示对应可操作错误，不得伪造文章或把失败当成功。

## 不在本阶段实现

端侧 TTS/OCR、历史统计、通知、备份导入恢复、对无译文来源的 AI 补译。
