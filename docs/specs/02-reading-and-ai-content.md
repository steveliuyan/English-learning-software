# 阶段 2：每日文章、双语阅读与自定义 AI Spec

## 目标

让用户在阶段 1 已解锁时选择文章类型并通过用户自配 AI 生成复习短文；确保 AI 不可用时不影响学习完成和历史阅读。

## 前置

完成阶段 0、阶段 1；需要 `AiProvider`、SecretStore、TodayPlan 解锁状态和文章本地存储。

## 范围

### F2-01 阅读访问与文章状态

- 仅在 TodayPlan 已解锁时允许生成当天推荐文章；历史已生成文章在任意日期可离线重读。
- 用户可选新闻、故事、科普、职场；保存默认文章类型偏好。
- 最终文章长度优先级：用户显式档位 > 词书等级默认 > 产品默认。默认标准档：小学/初中 80–120 词、高中 120–180 词、四级/六级/考研 180–300 词。
- 简短、标准、长篇的数值范围与长度容差由实现计划锁定；输入值必须受限，禁止任意长度。

### F2-02 AI Profile 与安全调用

- 支持多个 OpenAI-compatible AI Profile：名称、官网、HTTPS 公网 Endpoint、模型、能力（text/vision/tts）、高级参数及 SecretStore 的 Key 引用。
- Endpoint 必须通过 AGENTS.md 定义的 URL 与网络安全校验；Profile 切换不得复用其他 Profile 的 Key。
- 调用前显示域名和数据出站确认；文本能力调用首次确认，图片能力每次确认。
- 只允许 `temperature`、`top_p`、`max_tokens`、`timeout_seconds` 与受控系统提示模板；按 AGENTS.md 范围拒绝未知参数。
- 按错误类型返回可行动状态：未配置、能力不支持、离线/DNS、401、429、5xx、超时、取消、响应不合格。

### F2-03 文章生成与质量校验

- 生成请求包含：当天完成词集合、词书等级、类型、最终长度、语言偏好和已知排除条件。
- AI 返回必须包含标题、英文正文和中文翻译；系统派生词汇命中位置和未覆盖词列表，禁止信任模型提供的高亮坐标。
- 保存前校验：字段完整、正文与译文非空、英文/中文语言符合预期、长度处于容差、输出大小受限、无危险富文本/脚本、内容安全策略通过。
- 同一日期、活动词书、文章类型与长度档默认复用成功结果。换一篇必须由用户主动触发，并保存新版本、生成时间、模型名与参数摘要（不含 Key）。每日重生成次数与历史保留上限由实现计划决定并显示成本提示。

### F2-04 阅读体验

- 提供英文原文、可展开的全文中文翻译、高亮目标词、未覆盖词列表、点击词的离线词典入口与发音入口。
- 默认显示模式可设置：英文优先、双语对照、默认展开全文翻译；切换只改变展示，不改写文章。
- 内容只以安全文本/受控富文本渲染，禁止 HTML、脚本、外部链接自动执行。

### F2-05 离线降级

- 已缓存文章、译文和本地词典释义必须离线可读。
- 无网络、未配 Key 或 AI 失败时：保留今日已完成状态；显示重试、检查配置或阅读历史文章入口；不得显示伪造文章或将失败当成功。

## 验收标准

- AC2-01：严格模式未满足 TodayPlan 解锁条件时，文章生成入口不可用并显示新增/复习不足原因；已解锁时可进入类型选择。
- AC2-02：生成成功后文章含标题、英文、中文翻译、派生高亮与未覆盖词；文本不执行脚本或外部链接。
- AC2-03：同日同类型同长度重复进入复用同一文章；用户触发换一篇后生成新版本，旧版本仍可读。
- AC2-04：未配置 Key、HTTP Endpoint、私网 Endpoint、401、429、超时和畸形响应均返回对应可操作错误，学习完成状态保持。
- AC2-05：断网后已缓存文章可阅读；不可生成新文章且不会损坏今日计划。
- AC2-06：备份逻辑快照与日志中只保存 Profile 非敏感字段和脱敏诊断，不含 API Key 或 Authorization。

## 不在本阶段实现

端侧 TTS/OCR、历史统计、通知、备份导入恢复。
