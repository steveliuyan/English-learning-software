# 阶段 4：历史、提醒、备份迁移与安全恢复 Spec

## 目标

在无账户、无云同步的前提下，让用户可查看本地学习历史、使用可靠提醒，并在换机时以不可绕过的认证与完整性校验安全恢复数据。

## 前置

阶段 0 与阶段 1、阶段 2 已完成；可选 AI 音频备份依赖阶段 3。

## 范围

### F4-01 历史、收藏与统计

- 按日期展示活动词书、新词/复习完成数、完成状态、解锁规则、文章生成状态和阅读状态。
- 历史文章可离线重读；用户可管理文章版本、查询历史、收藏词和错词列表。
- 基础统计包括累计学习词数、累计复习数、连续学习天数和每日完成率。连续学习以当日计划快照内的解锁条件满足为准，不要求阅读文章。
- 删除词书后仍保留学习历史和文章；删除文章、音频、历史或学习数据必须显示级联影响并二次确认。

### F4-02 本地提醒

- 提醒默认关闭。用户开启时请求 Android 13+ `POST_NOTIFICATIONS`；拒绝后不重复强制请求，设置页提供系统设置入口。
- 用户配置本地日常提醒时间。V1 使用非精确调度，允许系统延迟，并在设置说明；每天最多一次、不补发。
- 当日计划已完成、提醒关闭、改时间、设备重启、跨日或时区变化时，取消旧任务并重新安排唯一的下一次提醒。
- 到点仅在当日计划未完成时提示“今日仍有学习/复习任务”，通知不得包含 API Key、原图、OCR 文本或文章内容。

### F4-03 备份导出

- 导出范围：学习档案、词书进度、学习事件、今日计划、文章、收藏、查询历史；可选 AI 音频和用户主动保存的拍照翻译记录。
- 不导出 API Key、Keystore 密钥、系统 TTS 数据、临时图片或任何调试日志。
- 使用逻辑快照生成自描述备份包，包含版本、manifest、实体数据、资源索引、资源关系、单文件及整体 SHA-256、签名元数据、迁移认证元数据和可选加密元数据。禁止复制数据库文件作为备份。
- 导出前显示范围、大小估算、未包含 API Key 的说明及“无账户下请自行妥善保存备份”的风险提示。

### F4-04 配对认证、密码与恢复

- 换机认证采用旧设备一次性、短时有效的挑战响应配对。旧设备必须通过本地设备解锁/生物识别或系统凭据确认后生成二维码/迁移码；新设备扫描/输入后完成挑战响应。静态码、截图或仅包内公钥不能替代该流程。
- 可选备份密码用于机密性保护。安全设计必须选用成熟的 AEAD 加密和带盐、内存硬 KDF；实现不得自定义密码学算法或参数。
- 新设备导入先在隔离临时目录解包并限制总大小、文件数、解压比、路径；拒绝 Zip Slip、路径穿越、重复实体、未知格式与畸形数据。
- 导入按顺序验证：支持版本、manifest schema、配对挑战、签名覆盖范围、可选密码、文件哈希、整体哈希、资源关系、实体引用和存储空间。
- 任一失败必须 fail-closed：清理临时文件、正式数据零写入、仅展示非敏感失败类别。无旧设备、旧设备损坏、配对失败、密码遗忘或签名失败时，受保护备份不得恢复，且不提供跳过校验/强制恢复。
- 全部验证成功后只支持“替换本机数据”；先创建可验证回滚点，经用户二次确认后原子切换数据与资源，重建提醒和缓存索引。恢复成功后所有 AI Profile 均为“需重新填写 Key”。

## 验收标准

- AC4-01：完成两天学习后历史分别显示两日的计划、完成数、文章状态；第二天不改写第一天数据。
- AC4-02：启用提醒后，未完成日最多收到一次提醒；完成、关闭提醒、变更时间、重启和时区变化均不会留下幽灵通知。拒绝通知权限后无循环弹窗。
- AC4-03：正常导出后，manifest 能列出所有导出实体和资源；包内不存在 API Key、Keystore 机密、系统 TTS 数据或临时图片。
- AC4-04：新设备以有效的一次性配对挑战和正确密码（如设）恢复后，数据和选定资源完整可读，AI Key 不存在，提醒被重新安排。
- AC4-05：篡改任一 payload/resource/manifest 字节、使用过期/已使用/截图转发的配对凭据、错误密码、路径穿越压缩包、资源缺失、空间不足或版本不支持时，导入失败且导入前正式数据逐字节不变。
- AC4-06：受保护备份在旧设备不可用或密码遗忘时不可恢复；UI 不提供跳过认证或强制导入入口。

## 不在本阶段实现

账号同步、云备份、WebDAV、跨设备自动同步、备份合并。
