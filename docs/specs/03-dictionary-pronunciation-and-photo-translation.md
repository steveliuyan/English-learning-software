# 阶段 3：离线查词、发音与拍照翻译 Spec

## 目标

提供可离线查询和基础发音的语言辅助能力；在用户明确同意后，将 OCR 文本或图片交由自定义 AI 服务翻译或生成在线语音。拍照翻译进一步提供「原位译文覆盖」（把原文擦掉、在同一位置顺原排版画译文，F3-04）与「悬浮窗屏幕翻译」（识别屏幕上其它 App 的文字并在原位覆盖译文，F3-05）。

## 前置

完成阶段 0。AI 翻译/在线语音依赖阶段 2。文章中的查词联动依赖阶段 2。

## 范围

### F3-01 离线查词

- 首页提供明显的搜索入口，支持英文单词和短语查词；查询默认不区分大小写，trim 并折叠连续空白。
- 本轮搜索只查询已安装词书元数据对应的真实词卡，内置/导入词书均通过 `WordCardSource` 读取；明确排除 `PlaceholderWordCardSource` 内容，不将其视为完整词典。
- 精确命中优先，其次前缀、包含；限制查询长度和结果数量，结果显示 lemma、释义和来源词书名称。
- 查询在后台执行，支持取消与请求代次校验；清空输入或关闭搜索页后，旧结果不得回写。读取失败显示可重试错误；未命中需明确提示当前仅支持已安装词书而非完整词典。
- 选择结果打开只读词卡详情，复用已有发音 Provider；不写学习记录、不保存历史收藏、不显示“重新学习”。详情发音状态以当前词卡快照和请求代次校验，关闭后迟到状态不得污染下一次详情。
- 阅读页的首页搜索入口与正文选词入口共用同一个本地搜索 overlay：正文未命中词以实际选中的单词或短语预填并立即查询；从搜索结果进入详情后返回仍停留在搜索结果，关闭搜索后回到原文章并保留阅读位置与选词状态。此范围只补多入口接线，不新增第二套搜索、AI、历史或收藏能力。
- 本轮不提供 AI 补充释义/翻译；离线未命中只提示当前仅支持已安装词书而非完整词典。AI 补充仍属于后续阶段范围，若实现必须标记来源为 AI。
- 本轮不保存查询历史、不提供收藏；查询历史和收藏行为仍属于后续阶段范围。

### F3-02 发音 Provider

- 统一暴露播放、暂停、重播、速度和错误状态。
- 默认系统 Android TTS；检测英语离线包或可用引擎，缺失时给出设置指引。
- 用户可下载安装经许可核验的 sherpa-onnx/Piper 英语模型；下载前展示大小、模型许可、存储需求，支持删除模型。
- 用户配置的 TalkifyTTS 或其他 AI TTS 仅在 Profile 声明语音能力且用户主动选择时使用。
- AI 音频缓存键为规范化文本、语音参数与模型版本；保存 SHA-256、大小、来源、创建时间与关联实体。哈希不一致时拒绝播放/导出并允许重新生成。
  本条需求未改动；落盘形状见 `docs/decisions/2026-11-05-ai-audio-cache-integrity-ledger.md`
  （sidecar 台账 + 读侧必查）；「关联实体」的实现层级已升到主键级，口径与取舍见
  `docs/decisions/2026-11-05-pronunciation-entity-ref-threading.md`（记「哪张卡/哪篇文章触发了这次合成」，
  实体不进缓存键；无主键的入口如实记 `Unattached`，禁止用词目当主键）。
- 系统 TTS 不产生、保存或导出音频文件。

### F3-03 拍照 OCR 与翻译

- 相机入口请求 CAMERA；相册入口按 Android 系统版本请求最小化照片访问权限。
- OCR 主路径为 ML Kit，检测到无 GMS 或不可用时降级 Tesseract。两者只返回文本、文本块坐标与置信度；OCR 本身不称为翻译。
- 对低置信文本给出标识，用户可编辑 OCR 文本。
- 图片和 OCR 文本默认仅在短期临时目录；用户取消、OCR 失败或退出后必须清理临时文件。
- 用户确认文本后才能发起 AI 翻译。发送图片或文本到第三方 AI 前每次显示目标域名、发送内容类别并要求明确确认。
  这条**有意严于** `docs/specs/02-reading-and-ai-content.md` F2-02 的一般规则（文本能力在查词问答与长难句分析两屏可按域名确认一次）：
  拍照翻译送出去的是设备里识别出的第三方文本，用户每次都要知道发的是哪一段，故保持逐次，冲突时取较严格一侧。
  裁定见 `docs/decisions/2026-11-05-ai-outbound-confirmation-granularity-and-network-security-config.md` D-1。
- 翻译页提供原文/译文对照、复制、选词查义和发音；失败时保留可编辑 OCR 文本并显示重试，不保留误导性半成品译文。
- 用户明确保存后，才将原图、OCR 文本与译文写入历史；保存资源进入备份可选范围。

### F3-04 原位译文覆盖（TATI：Translate Any Text in Image）

目标形状由用户 m06268 定调：「检测文字框坐标 → 把原图原文抹掉（inpaint/背景填充）→ 在同一个位置、顺着原来排版画上译文」，不是把文字抽出来另放一块。

- OCR 结果必须携带**块级**信息：每块 = 该块的文本、包围盒（left/top/right/bottom）、置信度、行朝向（横/竖）。只有整段字符串、没有块的实现不得承载原位覆盖。
- 翻译按「一屏/一张图一次请求」打包：把全部块按序编号发出（上行只有文本，不含图片字节），模型只回一个 JSON 数组 [{id, translation}]。失败与缺失分两档，判据唯一：**整批失败**——非 JSON 数组、数组项不是对象、id 非法、未知 id、重复 id、条目数**多于**请求数（模型自编了块）、单条译文超长或含脚本/框架标记；整批失败时保留可编辑 OCR 文本并允许重试，不画半张图。**该块不覆盖**——条目数少于请求数（个别 id 缺席）或该条译文为空白；此时该块保留原图并标记，其余块照常绘制，整批不算失败。
- 出站确认仍逐次（沿用 F3-03 的严格口径，不并入 F2-02 的按域名一次台账）：一次成图翻译就是一次发送。
- 擦除与重绘：本轮用**背景取样填充**（取包围盒外扩一圈像素的中位数/连通底色填满，含边界模糊处理），不引入任何需要额外模型权重的图像修复网络。端侧 inpaint 大模型（LaMa 一类）列后续版本，启用前必须先核验权重许可并计入第三方台账与 APK 体积预算。
- 排版重绘规则：字号由块高推得并做上下限钳制；译文按块宽折行（中文按字、英文按词）；行数超出块高时可向上下各扩展至相邻块间隙的一半，仍放不下则截断加省略号并提供点按看全文；推导字号低于可读下限（11sp 等效像素）时，该块放弃覆盖、保留原图并标记「空间不足」，不做压扁到不可读的强行绘制。
- 低置信块（低于阈值）默认不覆盖，与 F3-03 的低置信标识一致，用户可在覆盖前逐块开关。
- 产物是**一张新的位图**：可在「原文 / 译文覆盖 / 上下对照」三种视图间切换，可保存到相册与分享（沿用既有 FileProvider 路径）。原图不被覆盖改写；临时文件随取消/退出清理（同 F3-03）。
- 覆盖结果不修改词卡、学习事件与今日计划；它与查词、发音的联动仍通过块内文本进行（点按块可查该词）。

### F3-05 悬浮窗屏幕翻译

- 机制选型：**MediaProjection 截屏 + 悬浮窗原位覆盖**。截屏帧只在本机内存与短期临时目录流转，任何情况下都不把图像上传；上行的只有 OCR 出来的文本，且每次发送前都要走 F3-03 的逐次确认。
- 不使用无障碍服务读取其它 App 的界面节点：那只能拿到文字、拿不到像素位置，做不了原位覆盖；且权限口径与上架审核风险都不可控。
- 权限与授权流程：悬浮窗需要 SYSTEM_ALERT_WINDOW（进入系统设置由用户手动开启）；截屏需要 MediaProjection 授权，Android 14 起每次会话都要用户点一次，因此设计为「一次会话内持续翻译，直到用户停止」，不假装可以永久后台免授权。前台服务 + 常驻通知（可一键停止）。
- 交互：一个可拖动的悬浮球/浮动条，三档——关闭 / 单次翻译当前屏 / 连续模式。连续模式默认节流（每 N 秒最多一次，N 默认 3 且可调），并对屏幕帧做指纹去重：同一屏指纹不重复发请求，滚动或切换页面才重发。
- 覆盖层是可点击穿透的独立 View 层：按块坐标画译文底 + 文字，样式与 F3-04 同一套排版规则（同一份渲染实现，只是目标画布不同）。用户拖动/缩放时覆盖层跟随源帧坐标而不是跟手错位。
- 停止、权限撤销、项目被杀（MediaProjection 回调停止）时立即释放 VirtualDisplay/ImageReader、移除覆盖层、删除临时帧，不留悬浮残影。
- 「这一屏没有可翻的英文」不是会话级错误：用户通常先在自己的中文界面上点开始、再切到要翻的页面，所以 OCR 读不出字、或整屏没有英文块时只提示一句（顺带说明「不是翻译失败」），**会话继续**，下一轮轮询或用户点悬浮条上的「单次」就会重试；只有真正没法自己好的情况（没悬浮窗权限、截屏授权被拒/被回收、本机没有 OCR、没有可用 AI 服务、网络失败）才结束会话。
- 连续模式必须给出成本可见性：本次会话已发请求数、目标模型名、可随时停止；不得暗示免费。
- 该功能在无 GMS 或 OCR 不可用时按 F3-03 的「OCR 不可用」分类报错，不得说成翻译失败。

## 验收标准

- AC3-01：断网、无 AI Profile 时，离线词典命中的单词可显示并由系统 TTS 发音。
- AC3-02：无英语离线包、端侧模型缺失或 AI TTS 失败时显示对应安装/下载/重试提示，词卡仍可继续。
- AC3-03：同一文本、语音参数和模型版本命中同一 AI 音频缓存；修改任一输入生成新缓存。篡改缓存文件后播放与导出均失败。
- AC3-04：无 GMS 时自动尝试 Tesseract；两个 OCR Provider 不可用时，说明 OCR 不可用而不是翻译失败。
- AC3-05：未经确认不上传图像或 OCR 文本；用户未保存时，完成/取消/失败后不残留原图于历史、媒体仓或备份。
- AC3-06：用户编辑 OCR 文本后，AI 翻译只接收编辑后的文本；失败后文本仍可复制与重试。
- AC3-07：OCR 结果携带块级文本、包围盒、置信度与朝向；缺少块级信息的实现不得进入原位覆盖流程。
- AC3-08：一屏块数为 n，模型返回条目数多于 n、id 未知或重复、或 JSON 不可解析时判整批失败、不产生覆盖图，可编辑原文与重试保留。
- AC3-09：返回条目数少于 n（缺某个 id）或该条译文为空白时，该块不覆盖且带标记，其余块正常绘制，整批不算失败。
- AC3-10：渲染器对给定块矩形与译文产出确定结果——字号在钳制区间内、译文在块宽内折行、放不下时截断加省略号；推导字号低于下限时该块保持原样并标记「空间不足」。
- AC3-11：低置信块默认不覆盖，逐块开关后行为随之改变；原图字节不被修改，输出为新位图，取消/退出后无临时文件残留。
- AC3-12：悬浮窗连续模式下，同一屏指纹在节流窗口内只发一次请求；停止后 VirtualDisplay/ImageReader 已释放、覆盖层已移除；截屏帧从未离开本机。
- AC3-13：MediaProjection 授权被撤销或系统停止项目时，服务自行结束并清理，界面回到未启动状态，不残留悬浮窗。

## 许可门槛

- 词典、Piper 声音模型、TalkifyTTS 及其上游在线服务的许可证、条款和商业再分发资格必须填入第三方台账后才能启用。
- 不可将 GPL-3.0 语音组件静态集成至闭源发布包；不可使用标注非商业用途的模型。
- 端侧文字检测/图像修复模型（若后续引入 LaMa 一类 inpaint 权重）必须在启用前把权重许可、来源与再分发资格写入第三方台账；未核验不得打包。
- 用户提到的开源参考项目（Screen-Translator / Overlay-Translator / Getup / ImageTra）仅作管线参考，其代码与权重不进入本仓；若确要引入，逐项核验许可后再走台账。
