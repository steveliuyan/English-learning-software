# F3 路线图（2026-09-25 用户拍板「全部」）

依据：`docs/reference/2026-09-25-competitor-ux-word-learning-and-reading.md`。
原则沿用：每批 TDD（红→绿→变异→全量回归）、每批独立提交推送、数据完整性 MD5 取证。
顺序按依赖与风险排，不做没有数据源的假功能。

## F3-01 快赢组（数据/基建全部现成）
- [x] A. 历史卡片点开旧版全文：`ReadingHistoryScreen` 卡片可点 → 复用 `ArticleReadingViewModel.load(article, cards=空)` 渲染；返回键回历史列表。
- [x] B. 进文覆盖词弹窗：打开文章时（每篇文章一次）底部弹「本文覆盖你已背的 N 个词」，列 coveredLemmas（区分今日已覆盖/未覆盖），可关闭不再弹。
- [ ] C. 阅读标记偏好：`reading_preferences` 扩展（是否下划线已背词、标记词表来源=当前词书固定 V1），高亮派生按偏好过滤；Room 迁移 + 设置入口放阅读页。

## F3-02 打卡闭环族
- 完成阅读动作（阅读页底部按钮）→ `learning_events` 记一条阅读完成事件。
- 打卡页（背完/读完回览词表 + 打卡按钮）、月历/成就页（周学习时长、完成度环）。
- 数据源：`learning_events`/`card_review_states` 现成，无迁移风险。

## F3-03 词上下文 AI 问答
- 复用 `AiHttpTransport`/出站确认/失败映射；提示词模板「以 X 词造句/辨析/谐音」；建议追问固定列表；保存笔记 = 本地表（新表）。
- 依赖：F2-02 残留「默认 Profile 选择」先落地（现在是第一套有 Key 垫底）。

## F3-04 AI 载荷扩展族（统一设计 `AiPayloadKind` 扩展）
- 长难句分析（结构化成分输出渲染）、文字 AI 中转生图（供提示词给生图服务）。
- 先出载荷 schema 与许可/成本评审（中转生图涉及把文本发第三方生图服务，出站确认必须覆盖）。

## F3-05 依赖词库闭合（PlaceholderWordCardSource 换真数据后才能做）
- 点词弹窗（释义/发音/重学→FSRS 重学队列）、例句/派生词、词典页、生词本。
