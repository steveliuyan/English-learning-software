# F3-03 词上下文 AI 问答 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在词卡详情页提供「问 AI」入口，对当前词提供三种固定问题（造句 / 近义辨析 / 谐音记忆）的 AI 回答，可保存为本地笔记；不提供自由提问。

**Spec:** `docs/superpowers/plans/2026-09-25-f3-roadmap.md`（F3-03）。前置「默认 Profile 选择」已落地（`DefaultTextProfileSelector` + Room v16 + 设置页接线）。

## Global Constraints

- 复用 `AiHttpTransport`、`AiChatRequestBuilder`、`requiredConfirmation` 出站确认与 `AiFailure` 失败映射；不新增网络路径。
- 提示词是受控模板：`WordQaKind` 三种固定类型，禁止自由提示词注入（V1 参数白名单约束的延伸）。
- Key 只进 `Authorization` 头、`CharArray` 流转并清零；日志/落库/错误消息零 Key（沿用 GenerateArticleUseCase 模式）。
- AI 输出按不可信输入处理：大小上限、非空校验；渲染为纯文本，禁止富文本解释执行。
- 笔记为本地新表 `word_ai_notes`（Room v17 迁移），只存 lemma/kind/回答/时间，不存 Key、Endpoint 或完整 Profile。
- 未配置默认 Profile / 无 Key / 无 Text 能力时返回「去配置」语义（NotConfigured），不与网络失败混用。
- TDD：先 RED 再最小 GREEN；关键断言做变异测试后恢复；真机 `install -r -t` + `am instrument`，禁止 `connectedDebugAndroidTest`。
- 不把受保护文件 `app/gradle.lockfile`、`core/error/AppError.kt`、`ui/AppViewModel.kt` 混入功能提交。
