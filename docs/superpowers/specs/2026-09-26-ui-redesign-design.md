# UI 重设计：苹果风玻璃拟态 + 域色多彩系统 设计文档

日期：2026-09-26
状态：已与用户逐节确认（OpenAI 移除范围 / 分批套用 / 薄荷绿+中性底 / 方案 A 自建组件库 / iOS 式域色配色）

## 0. 目标与非目标

**目标**
1. 语音朗读页移除 OpenAI 引擎选项（只留 系统 TTS + 小米 MiMo）。
2. 建立统一设计令牌层与玻璃拟态组件库，第一批落地「AI 与语音」域。
3. 配色从全绿单调改为 iOS 式域色多彩系统：中性底 + 每个功能域一个专属强调色。
4. 重设计按钮、弹窗、菜单、动效、字体排版，整体观感向苹果靠拢（克制、留白、层级）。

**非目标（本次不做）**
- 不引入自定义字体文件（苹果感来自排版层级与留白，非字体本体）。
- 不改页面信息架构与导航结构（层级重组已完成）。
- 不引入第三方 UI/玻璃拟态库。
- 批 2/批 3 之外页面的逐屏视觉替换。

## 1. OpenAI 引擎移除（语音域）

- `SpeechSettingsScreen` 引擎列表只剩「系统 TTS」「小米 MiMo」两行；OpenAI 行、其状态展示与相关详情逻辑移除。
- `PronunciationEngine` 枚举与 `OpenAiCompatiblePronunciationProvider` **代码保留不删**：
  - Room `speech_preferences` 存过 `OpenAi` 的历史数据必须能反序列化；
  - 不误伤底层回退链；UI 不再提供该选项即可。
- 若存储的选择是 `OpenAi`：语音页如实回落显示「系统 TTS」为当前供应商；用户点选任一行后自然覆盖存储。
- 测试：`speech_engine_status_openai` 相关断言迁移到 MiMo 行；新增「存储为 OpenAi 时回落显示系统 TTS」用例。

## 2. 设计令牌层（`ui/theme` 扩展）

### 2.1 域色系统（iOS 式多彩）
中性浅灰白底（约 `#F5F5F7`）+ 白色表面分层；每个功能域一个专属强调色：

| 域 | 强调色（初值，实现时可微调） |
|---|---|
| AI 与语音 | 薄荷绿（现 MintPrimary 演进，品牌锚点） |
| 学习（今日计划/单词卡） | 蓝 |
| 复习 | 橙 |
| 词库 | 紫 |
| 阅读 | 粉 |
| 设置/中性 | 石墨灰 |

- 图标、主按钮、强调元素用所在域的域色；底色、文字色全局统一。
- 令牌全局生效（底色/表面/文字色第一批就全 app 替换），逐屏域色套用分批进行。
- 深色模式：本次仅保证令牌结构可扩展，不交付深色主题（YAGNI）。

### 2.2 字体阶梯
display / headline / title / body / label 五级，统一字重与字距；全部通过令牌引用，消灭散落的 `fontSize`/`FontWeight` 魔数。

### 2.3 圆角
弹窗 24dp / 卡片 20dp / 按钮 14dp 或胶囊形，收敛为令牌。

### 2.4 动效常量
150 / 250 / 350ms 三档时长 + 统一缓动曲线（emphasized 风格），收敛为单一对象。

## 3. 玻璃组件库（`ui/components/glass`，新建）

- `GlassDialog`：系统 Dialog 窗口 + `Window.setBackgroundBlurRadius`（API 31+ 真模糊背后内容；设备 Android 13 支持）；API 31 以下降级为半透明 scrim（行为抽纯函数可 JVM 测）。
- 下拉菜单改**页内浮层**（Box overlay）：同窗口内才能对下层内容做真模糊；现有 DropdownMenu（音色下拉等）全部迁移。
- `GlassCard`（试听卡/分组卡）、`PillButton`（主/次/文字三级）、统一按压反馈（缩放 0.97 + 微透明度）。
- 铁律不变：所有交互元素同时提供 testTag 与 contentDescription。

## 4. 交互与动效规范

- 弹窗：缩放 0.92→1 + 淡入；scrim 淡入；关闭反向。
- 折叠区：`animateContentSize` + 透明度。
- 页面进入：淡入 + 轻微上移（150ms）。
- **严格遵守系统减弱动效**：`animator_duration_scale=0` 时动效归零（沿用项目既有纪律）。
- 玻璃弹窗出现时下层内容微模糊，关闭即恢复。

## 5. 分批交付

- **批 1（本次）**：OpenAI 引擎移除 + 全局配色令牌（底色/表面/文字）+ 玻璃组件库 + 「AI 与语音」域逐屏套用（设置一级卡、语音朗读页、AI 服务与密钥列表/编辑器、全部现有弹窗/下拉）。
- **批 2**：首页/今日计划、复习（蓝/橙域色落地）。
- **批 3**：词库、阅读、剩余页 + 全 app 一致性走查。

## 6. 测试与验证

- 全部现有测试保持绿（testTag 语义不变，仅视觉替换）；OpenAI 移除相关测试按第 1 节更新。
- 新增：组件降级纯函数 JVM 测试、OpenAi 回落显示用例、玻璃组件 Compose 用例（真机 Android 13 走真模糊路径）。
- 真机逐页截图核对；数据库三件套前后 MD5；全量 JVM + 真机 instrumentation 回归。

## 7. 风险

- 页内浮层替代 DropdownMenu 需要处理返回键/外点关闭与可访问性语义。
- 域色初值需真机观感校准，允许微调不改结构。
